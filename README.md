# Grey Wolf Optimizer (GWO) Implementation
# Optimal-Ambulance-Placement-With-GWO-Algorithm

This repository contains a Python implementation of the **Grey Wolf Optimizer (GWO)** algorithm, a meta-heuristic optimization method inspired by the social hierarchy and hunting mechanism of grey wolves.

## 📌 Overview
The goal is to solve optimization problems by simulating the leadership hierarchy and hunting behavior of grey wolves.

## 🐺 Features
- Implementation of the social hierarchy (Alpha, Beta, Delta, And Omega).
- Mathematical modeling of Encircling, Hunting, and Attacking mechanisms.
- Visualization of the convergence curve (Fitness over iterations).

## 🚀 How it Works
1. **Social Hierarchy:** The best solution is Alpha (ɑ), followed by Beta (β) and Delta (δ).
2. **Encircling Prey:** Wolves update their positions based on the prey's location.
3. **Hunting:** Guided by ɑ, β, And δ to find the Optimal Solution.
